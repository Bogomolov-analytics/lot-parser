# Автоматизация поиска лотов (lot-parser)

![Пример работы бота](https://raw.githubusercontent.com/Bogomolov-analytics/lot-parser/main/2026-10-20_15-36-28.png)

## Что это
Скрипт на Python для автоматического поиска, фильтрации и анализа лотов на торговых площадках. Бот не просто собирает ссылки, а выдает аналитику: оценивает ликвидность, маржинальность и риски.

## Зачем это нужно
Ручной поиск лотов занимает часы. Скрипт делает это за минуты, отсеивает мусор и присылает в Telegram только те варианты, которые стоят внимания.

## Стек
- **Язык:** Python 3
- **Библиотеки:** requests, BeautifulSoup, pandas, selenium
- **Интеграции:** Telegram Bot API, работа с API площадок
- **Данные:** JSON, Excel/CSV

## Что умеет
- Собирает данные с площадок (парсинг).
- Фильтрует по заданным критериям (цена, категория, регион).
- Проводит первичный анализ (выявление аномалий, оценка рисков).
- Отправляет уведомления в Telegram-бота.

## Как запустить (для разработчиков)
1. Клонировать репозиторий: `git clone ...`
2. Установить зависимости: `pip install -r requirements.txt`
3. Создать файл `.env` и добавить туда `TELEGRAM_TOKEN` и `API_KEY`.
4. Запустить: `python search_lots.py`

## Результат
Автоматизирован ручной поиск: время сокращено с 2 часов до 5 минут. Бот присылает готовый отчет с рекомендациями по каждому лоту.
