# lot-parser
Автоматизация поиска лотов. Парсинг данных с площадок, обработка, уведомления в Telegram.
## Что делает
- Собирает данные о лотах с торговых площадок (парсинг).
- Фильтрует по заданным критериям (цена, категория, регион).
- Формирует отчёт в таблице.
- Отправляет уведомления в Telegram-бот.
## Стек
- Python (requests, BeautifulSoup, Pandas)
- API
- Telegram Bot API
- Git
## Как запустить
1. Установить зависимости: `pip install -r requirements.txt`
2. Запустить скрипт: `python parser.py`
3. Получить уведомления в Telegram.
   ## Результат
Автоматизирован ручной поиск лотов: время сокращено с 2 часов до 5 минут.
